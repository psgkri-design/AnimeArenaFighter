ANIME ARENA FIGHTER — UPDATE LOG

VERSION 0.1.0 — 2026-09-27
==================================================
- Created initial Godot 4.7.2 project.
- Added Android export preset for ARM64.
- Added automated APK build with GitHub Actions.
- Added 1v1 arena prototype.
- Added third-person combat camera and lock-on.
- Added touch joystick and mobile action buttons.
- Added light combo, heavy attack, dash, dodge, block and parry.
- Added stamina, energy and ultimate gauges.
- Added four prototype skills.
- Added enemy AI.
- Added KO / victory / defeat / rematch flow.
- Added toon/energy shaders.
- Added 30 FPS and 60 FPS options.

VERSION 0.2.0 — 2026-09-27 — CHARACTER SELECT / ROSTER UPDATE
==================================================
- Forced mobile orientation to sensor-landscape only.
- Added runtime landscape enforcement through DisplayServer.
- Added permanent fighter roster data file.
- Expanded roster to four fighters:
  1. Succubus Assassin — rushdown / air mobility.
  2. Arcane Mage — ranged zoning / control.
  3. Templar Knight — tank / power.
  4. Cyber Bunny — mobility / burst.
- Added unique health, stamina, speed, power and defense values per fighter.
- Added variant-specific skill damage profiles and combat tuning.
- Added visibly different procedural character silhouettes and outfit pieces:
  horns, demon wings/tail, mage hat/staff, templar cape/armor/weapon,
  bunny ears/techwear/orange accents.
- Rebuilt main menu as a landscape BATTLE SETUP screen.
- Added independent YOUR FIGHTER and OPPONENT selection.
- Added fighter role, description, stats and skill-list panels.
- Added Easy / Normal / Hard AI selector.
- Added Character Select return path from pause and results screens.
- Increased arena decorative pillar count and refined lighting/background values.
- Updated match startup to preserve selected player, enemy and AI difficulty.
- Next target: integrate higher-quality licensed external 3D character assets and animation sets.

==================================================
VERSION 0.2.1 — 2026-09-27 — REAL 3D ASSET INTEGRATION
==================================================
- Added automated download of KayKit Adventurers assets during Android CI builds.
- Asset license verified as CC0 1.0 / commercial use allowed.
- Integrated four rigged/animated GLB character bases:
  Rogue Hooded, Mage, Knight and Rogue.
- Mapped those bases to the four game fighters.
- Added automatic idle-animation discovery/playback.
- Added custom procedural overlays on top of the imported models:
  demon horns/wings/tail, mage magic accents, templar cape/cross,
  cyber-bunny ears and orange tech accents.
- Added graceful fallback to the internal procedural models when external assets
  are not present in a local source checkout.
- Added ASSET_SOURCES.txt to track external asset provenance and licenses.
