# Anime Arena Fighter

Android 3D anime arena-fighter prototype built with **Godot 4.7.2**.

## Current release

**v0.3.1 Combat Identity / Audio / UI Polish**

- Landscape 16:9 Android build.
- Four playable fighters with rigged models, fighter-specific animations and CC0 weapon assets.
- Character Select with animated 3D preview and independent player/opponent selection.
- Third-person 1v1 arena combat with lock-on, AI, combo attacks, skills, dodge, block/parry and Ultimate.
- Fighter-specific projectile shapes, skill mechanics, pooled combat VFX and cinematic Ultimate feedback.
- Original pooled 3D combat audio, hit-stop, camera impulse and Android haptics.
- Live mobile skill cooldown / energy / Ultimate button states.
- LOW / MEDIUM / HIGH mobile graphics presets.
- Automated Android APK build plus full headless gameplay smoke validation.

See `CHANGELOG_GAME.md` for detailed changes and `assets/ThirdParty/ASSET_LICENSES.md` for external-asset licenses.
